## Design System

### Color Palette

| Color | Code | Usage |
| --- | --- | --- |
| Primary Blue | `#2b6cb0` | Primary buttons, links, active state |
| Dark Blue | `#1a365d` | Navigation header, headings |
| Light Blue | `#dbeafe` | Info badge background, highlights |
| Green | `#16a34a` | Success status, completed state, pass indicator |
| Light Green | `#e8f5e9` | Success badge background |
| Red | `#e53e3e` | Error, fail indicator, danger actions |
| Light Red | `#fee2e2` | Error badge background |
| Amber | `#d69e2e` | Warning, pending status, star ratings |
| Dark Gray | `#333` | Primary text |
| Medium Gray | `#666` | Secondary text |
| Light Gray | `#999` | Placeholder, disabled text |
| Border | `#ddd` | Borders, dividers |
| Background | `#f5f5f5` | Page background |
| White | `#fff` | Card background, input fields |
